TakaBazar V12.4 — Balance Sync Fix

What changed:
- Fullscreen games now always show a compact premium TakaBazar Balance pill.
- The old yellow outer balance is NOT restored.
- Balance pill is teal/glass style and refreshable.
- It updates through the central TakaBazar wallet after bet/cancel/cashout.
- On server startup, every already-installed game HTML file is scanned.
- Old game HTML is automatically repaired to load the current TakaBazar Game SDK + Auto Bridge.
- This means previously installed SkyRush does not need to be re-uploaded.
- Game HTML uses no-store caching, preventing an old cached copy from hiding the fix.
- Existing users, wallet balances, deposits, withdrawals, and installed games remain unchanged.
